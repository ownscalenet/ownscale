What ownscale can do, one feature per page. Each page says what the feature
is for, who can use it and where to find it in the console.

Most pages mention two kinds of users: **managers**, meaning users with the
`owner` or `admin` role, and **members**, meaning everyone else. See
[Users and roles]({{< relref "users-and-roles.md" >}}).
